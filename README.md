# Kuba AI Cycling Coach

Personal AI cycling coach focused on adaptive training around irregular 12-hour day/night shifts.

## MVP 0.1
- Today decision: TRAIN / REST / MODIFY
- Manual daily check-in
- Available training time
- Training plan context
- Garmin integration layer (next step)
- AI coach decision layer (next step)

## Stack
- Next.js + TypeScript
- Tailwind CSS
- Supabase/PostgreSQL
- Garmin Personal API
- OpenAI API
